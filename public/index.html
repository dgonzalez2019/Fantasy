Opens ESPN's own login page in a browser window. You type your password there — never here — and this app just picks up the session afterward.

Enter cookies manually instead

For headless servers, or if the browser login won't open. Sign in at fantasy.espn.com, then DevTools → Application → Cookies → espn.com and copy espn_s2 and SWID.

Yahoo

Standard Yahoo sign-in. One-time app setup required.

Not linked

Sends you to Yahoo's own sign-in page. Your password is never entered here.

App credentials (one-time setup)

Yahoo requires every app to register its own credentials. Create one at developer.yahoo.com with Fantasy Sports Read permission and paste the Redirect URI below into it. Best set once in .env as YAHOO_CLIENT_ID / YAHOO_CLIENT_SECRET. Yahoo requires an HTTPS redirect, so local use needs a tunnel such as ngrok.
